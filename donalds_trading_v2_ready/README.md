# Donald's Trading — Performance Lab

A light, purple-accented Streamlit trading analytics portfolio built from the supplied Excel trading journal.

## What it shows
- Starting capital, current balance, total profit, win rate, best-performing coin, target attainment
- Overall progress timeline and week-by-week drill-down
- Full trade journal with filters
- Equity/growth curve, P&L by week/day, coin leaderboard, wins vs losses
- Risk, target, capital allocation and best/worst trade analysis
- Interactive profitability simulator
- Excel workbook upload and CSV/report downloads
- Workbook audit and project/technology explanation

## Deploy on Streamlit Community Cloud
1. Create a new GitHub repository.
2. Upload **all files and folders from this project** to the repository root.
3. In Streamlit Community Cloud, create an app from that repository.
4. Set the main file path to `streamlit_app.py`.
5. Deploy.

The bundled workbook must stay named `trading_data.xlsx` in the same folder as `streamlit_app.py`.
